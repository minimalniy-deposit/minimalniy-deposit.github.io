# Понедельничная проверка: семь цифр на площадку

Файл: `src/data/casinos.json`. Для каждой из 12 площадок заполните поля ниже (число без пробелов, в рублях; если не нашли — оставьте `null`). Одна правка — и в понедельник робот пересчитает таблицы, калькуляторы и первые абзацы страниц депозита, а изменение запишет в историю условий.

| Поле | Что искать | Где | Пример |
|---|---|---|---|
| `minBetStarburst` | минимальная ставка за спин в Starburst | открыть слот в кассе (можно в демо внутри кабинета — важно, чтобы в рублях), ставка «−» до упора | `1` |
| `minBetGates` | минимальная ставка в Gates of Olympus | то же | `20` |
| `bonusMinDeposit` | минимальный депозит, при котором начисляется приветственный бонус | «Акции» → приветственный бонус → правила; строка «минимальный депозит для получения бонуса» | `500` |
| `maxBetWagering` | максимальная ставка во время отыгрыша | там же, пункт про «максимальная ставка при активном бонусе» | `500` |
| `wagerDays` | срок отыгрыша, дней | там же, «бонус действует N дней» | `7` |
| `withdrawMinAmount` | минимальная сумма вывода через СБП | касса → вывод → СБП, подсказка под полем суммы | `500` |
| `licenseVerifyUrl` | ссылка проверки лицензии | подвал сайта казино → клик по печати лицензии; для Кюрасао адрес вида `https://cert.cga.cw/certificate?id=…`, для Anjouan — `…/validate?domain=…` | `https://cert.cga.cw/certificate?id=eyJ…` |
| `termsUrl` | страница правил / условий бонуса | подвал → «Правила», «Terms», «Бонусные условия» | `https://7k-casino.ru/rules` |
| `siteDomain` | домен сайта, куда ведёт ссылка после редиректа | адресная строка после перехода по кнопке «Играть» | `7k-casino.ru` |
| `cashierUsdtRate` | сколько рублей касса просит за 1 USDT | касса → пополнение → USDT, ввести 100 ₽, посмотреть пересчёт **до** подтверждения | `91.4` |

Порядок: касса → пополнение (USDT-курс, минимум) → вывод (минимум СБП) → акции → правила бонуса (три цифры) → два слота. На площадку — 3–4 минуты, на все двенадцать — около 40.

Правила:
- Записывайте то, что показывает касса **сегодня**, а не то, что написано в обзорах.
- Если у площадки нет Starburst или Gates of Olympus — `null`; страница честно напишет «не проверено».
- Если бонус начисляется от любого депозита — `bonusMinDeposit` = минимальный депозит кассы.
- Если в правилах написано «до 10% от бонуса» — переведите в рубли для бонуса на 500 ₽ (например, 200%·500 = 1 000 ₽ бонуса → потолок 100 ₽).

Проверить, что всё на месте: `node scripts/check-data.mjs` — строки «monday field … not verified» должны исчезнуть.
